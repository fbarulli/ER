# DATACLASS BRIEF (owner directives, 2026-10-08/09)

Read `ER/dataclass.md` (hosted-dataset requirements) and this file. These are
standing directives for ALL class work.

## Hard rules
- Model: agents run on `deepseek-v4-flash` (no other model).
- **Pydantic classes.** All data owners are Pydantic models.
- **Bake behavior into the class.** Consumers ask the class; they do not
  re-spell literals or re-derive. Rich methods on the class, not free helpers.
- **SRP.** One owner per concern; **every method does one thing**; no
  god-functions; helpers private; tests target the **public API only**.
- **SSOT via YAML.** Every path/slug/role/set declared ONCE in a config yaml.
  Code resolves through `core.common.F` / `core.common.artifact` (or the
  class's own yaml loader). **No path literals in code.**
- **Tracebacks.** Every caught/handled error records the FULL traceback
  (`traceback.format_exc()` / `exc_info=True`); no truncated one-liners; no
  silent fail-soft. Fail loud on real runtime errors only.
- **Naked data, no hash.** No freshness/staleness/hash/version/exists gate.
  NO content digest anywhere (see `agent/.hash-removal-brief.md`). Identity is
  STRUCTURAL: run tag + member names + byte sizes + row/col counts.
- **Minimal testing.** At most one focused test per public behavior; do not
  build large test matrices.
- Do NOT run git. Do NOT run the full suite.

## Official datasets (ONLY these three exist)
1. `dataset.csv` — the ONE original/source export (repo root; bound as `files.dataset`).
2. `dataset_3k.csv` — the 3k set (repo root).
3. `data/prepared/smoke_200` — the smoke set.
**Everything else is binned** (delete): `data/prepared/smoke_500`,
`data/prepared/*__clean_shared_inputs`, `data/track_setup__clean_shared_inputs`,
retired `sample_3000/5000` bindings, and any other derived "set".

## Splits
- **laya**: train / dev / validation.
- **full**: full + validation only (may change).
- **smoke**: no splits.
- **Validation size must be FLEX (configurable), not a fixed count.**
- Open: who owns all the splits / unowned splits -> the cartographer agent maps
  this; the `Dataset` class is the intended owner of its own splits.

## Class inventory (composed, SRP, no god-class)
- `Dataset` (`src/core/dataset.py`) — owns the original dataset + the three
  official sets + their splits; hands the original to `Bundle`. Never seals.
- `HostedRegistry` (`src/core/hosted_dataset.py`) — hosted Kaggle/Colab dataset
  slugs per `dataclass.md`. Sibling to `Dataset`, not mixed in.
- `Artifacts` (`src/core/artifacts.py`) — collects the outputs of the training
  class and the Bundle class (checkpoints, per-track artifacts, metrics,
  traces/events, sealed archives).
- `Results` (`src/core/results.py`) — the results that live BETWEEN training and
  post-training analysis (ablation request/report/vectors, baseline threshold,
  holdout report).
- `Bundle` stays the sealed transport container only (no hashing).
