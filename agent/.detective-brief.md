# DETECTIVE BRIEF — post-consolidation audit (5 read-only detectives)

Run AFTER the current 5 agents (hash sweep, splits cartographer, hosted registry,
artifacts, results) have all reported. Read-only: do NOT edit, do NOT run git,
do NOT run the suite, do NOT spawn.

Ground truth to read first: `agent/.hash-removal-brief.md`,
`agent/.dataclass-brief.md`, `dataclass.md`, `agent/data_surface_map.md`.

Each detective owns one lens over the RECENT work (state the working tree as-is;
flag half-applied changes):

1. **Redundancy** — duplicate owners, parallel registries, two classes/paths
   doing the same job, second role/slug enums, dead helpers left behind.
2. **SSOT violations** — any literal re-spelled outside its yaml (paths, slugs,
   dataset names, roles, split names, run-tag formats), config keys with no
   owner, two sources of truth.
3. **Gaps** — surfaces with no owner (unowned splits, artifacts, results,
   consumers), classes whose consumers were never wired, set/bin-list misses.
4. **Compliance** — Pydantic, behavior baked in class, SRP one-thing methods,
   full tracebacks (`traceback.format_exc()`/`exc_info=True`, no silent
   fail-soft), minimal tests targeting public API, zero content hashing.
5. **Coverage/verification** — the three official datasets only
   (`dataset.csv`, `dataset_3k.csv`, `smoke_200`), binned sets actually gone,
   validation size flex, tests that would catch regressions.

Deliverable per detective: a findings table `file:line | offending text | why |
where it should live | severity`, plus a short "what I could NOT verify" list.
No fixes — findings only; the coordinator relays fixes.
